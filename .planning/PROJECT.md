# Video Editor Portfolio CMS + Super Admin Panel

## Objective
Build a world-class, production-grade, ultra-fast, highly scalable Video Editor Portfolio CMS platform with a complete Super Admin Dashboard. The system will operate under a multi-agent synchronized execution strategy.

## Key Goals
- Production grade / Scalable / Fast / Premium
- Multi-agent synchronized execution
- Super admin panel where the owner can manage everything without touching code.
- No placeholder code, no fake APIs, no demo architecture.
- Full stack: Frontend, Backend, Database, AI, Dashboard, Analytics.
- All code should be clean, modular, and use feature-based structure with SOLID principles.

## Tech Stack
- **Frontend**: React, Vite, Tailwind CSS, Framer Motion, Zustand, React Hook Form, Zod, Axios
- **Backend**: Node.js, Express
- **Database**: PostgreSQL (Neon), Prisma ORM
- **Auth**: JWT + Refresh Token
- **Storage**: Cloudinary
- **Caching**: Redis
- **Analytics**: Custom analytics system
- **Email**: Nodemailer
- **Deploy**: Vercel (Frontend), Railway/Render (Backend)

## Target Audience
Video editors and content creators looking to showcase their portfolio to clients seamlessly, while having a powerful backend to manage everything.
