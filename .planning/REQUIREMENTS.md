# Requirements

## Global Core Rules
1. Clean architecture, reusable components, modular architecture
2. SOLID principles, service layer pattern, DAO pattern, feature-based structure
3. Strong Type Safety, Production-grade naming
4. Mobile-first, responsive
5. API optimization, lazy loading, dynamic imports
6. Caching, image optimization, WebP, asset compression
7. SEO optimization, skeleton loading
8. Security first (JWT, CSRF, XSS, Rate limiting)
9. Testing ready, deployment ready

## Features

### Public Website
- **Home**: Hero section, Background video, Stats, CTA
- **About**: Profile, Skills, Tools
- **Services**: Pricing packages
- **Portfolio**: Categories, Video previews, Filters, Search, Pagination, Infinite scroll, Featured projects
- **Other Pages**: Testimonials, Contact, Blog Section, FAQ, Footer

### Admin Dashboard (Super Admin)
- **Dashboard**: Analytics (total projects, visitors), recent activity, charts, growth analytics.
- **Portfolio Manager**: Add/Edit/Delete projects, bulk actions, draft/publish modes, schedule publishing, reorder projects.
- **Content Manager**: Manage Hero, About, Services, Testimonials, Footer, Contact info.
- **Media Manager**: Upload image/video/thumbnail, folder management, search, delete.
- **CRM**: View/Search inquiries, add notes, change status.
- **Theme Manager**: Colors, fonts, layout, hero styles, card styles, background settings.
- **SEO Manager**: Meta title, Meta description, Keywords, Sitemap, Open graph.
- **Role Management**: Admin, Editor, Viewer.
- **Settings**: Site settings, Social links, Resume upload, Contact settings.

### AI Features
- AI project description generator
- AI title generator
- AI caption generator
- AI hashtag generator
- AI SEO generator
- AI testimonial formatter
- AI portfolio helper

### Analytics & Performance
- **Analytics**: Total visitors, page views, top projects, traffic source, device/country analytics, conversion tracking, click tracking.
- **Performance**: Code splitting, API caching, DB optimization, 95+ Lighthouse score.
